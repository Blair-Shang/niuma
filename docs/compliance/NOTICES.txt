Oracle Instant Client (optional, not bundled by default)
--------------------------------------------------------
NiuMa's Oracle module uses ODPI-C and may load Oracle Instant Client libraries
when the user connects to Oracle Database. Instant Client is NOT included in
the default NiuMa installer.

Users may:
  1. Use an existing Instant Client / Oracle Client via ORACLE_HOME or PATH; or
  2. Download Instant Client from Oracle and point NiuMa to oci.dll via
     Settings → Tool Components → Oracle Instant Client
     (NiuMa injects the standard ORACLE_HOME variable for the oracle-service process).

Redistribution of Instant Client (if a future edition bundles or proxies the
download) is subject to the Oracle Technology Network Development and
